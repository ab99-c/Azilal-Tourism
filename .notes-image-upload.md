# Image upload feature — plan notes

## User request
Owners can upload images for their restaurants & cafes easily from the dashboard.

## Key facts learned
- `server/storage.ts`: `storagePut(relKey, data: Buffer|Uint8Array|string, contentType)` → `{ key, url }` where url = `/manus-storage/{key}` (auto-served via signed redirect).
- Max S3 object size via forge: keep uploads ≤ 5MB (validate client+server).
- restaurants & cafes tables have `image` text column already (nullable).
- Owner procedures exist: `ownerProcedure` in server/routers.ts (adds ctx.ownerId); `requireOwnership(ctx, item, itemKind)` gates update/delete; dashboard.myRestaurants/myCafes scoped.
- Cars/hotels also have image columns but user asked only restaurants & cafes.
- Test pattern: server/restaurants-cafes-ownership.test.ts uses `makeCtx(userId)` helper: `{ req: {headers:{}}, res: {clearCookie()}, user }`.
- Tests run with real DB; clean up test rows after runs (`DELETE FROM restaurants WHERE nameEn LIKE 'Test%'`).
- vitest: 47 tests passing in 7 files.
- Live domain: azilaltour-j2sx2a5n.manus.space; auto-publish on checkpoint; GitHub remote: `git push github main`.
